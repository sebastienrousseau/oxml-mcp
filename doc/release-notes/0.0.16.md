# oxml-mcp 0.0.16

Release preparation dated 2026-11-06. This file does not announce a
publication or authorize a tag.

## Highlights ⭐️

* **`Host` and `Origin` checks on the HTTP transports**: The SSE routes refuse a foreign `Host` or a non-local `Origin` with `403`, so a page that rebinds its own name to `127.0.0.1` can no longer open `/sse` or post JSON-RPC to `/messages/`. Streamable HTTP applies the same `Host` and `Origin` lists.
* **JSON only on `/messages/`**: The SSE message route refuses any `Content-Type` but `application/json` with `415`.
* **A cap on live sessions**: `--max-sessions` (64 by default) bounds how many sessions each HTTP transport holds. SSE answers a stream past the limit with `503`; streamable HTTP refuses to create the session. Stateless `2026-07-28` requests open no session and are not counted.

## Upgrade notes

Rust 1.89.0 or newer is required. The `oxml = "=0.0.13"` and
`xmlschema = "=0.0.14"` pins are unchanged from 0.0.15, and the
unpublished fuzz harness moves to 0.0.16 with the crate.

On the HTTP transports, a browser client served from a non-local
origin, or a proxy that forwards a `Host` other than a loopback name or
the bound one, is now refused with `403`. Binding `0.0.0.0` or `::`
turns the `Host` check off; the `Origin` check stays. A deployment
that holds more than 64 concurrent sessions needs `--max-sessions`
raised. stdio is unchanged.

generated change list and the checksums of the attached assets.

and publishes the MCP Registry entry from the same tag.

The final source commit must pass the repository gate and published PR
checks before the tag is pushed.
